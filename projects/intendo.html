Intendo: choosing what matters today

A planning app that keeps goals, daily choices and review history together—with the same care for data integrity as for the interface.

September 2026 – presentPrivate personal project

A fresh day should be a choice

Intendo connects longer-term goals with the intentions chosen for a particular day. Outcomes and reflection stay in the history; unfinished work carries forward only when deliberately selected.

What I built

I built the React/TypeScript interface, SQLite and Cloudflare D1 persistence, and an agent CLI. The product supports both direct interaction and carefully scoped agent changes.

  • Revision-checked saves prevent stale edits from silently overwriting newer work.
  • Planner state and activity history are committed together in a transaction.
  • Agent changes can be previewed, confirmed and verified, with stale previews rejected.

The design constraint

The app supports human judgment. A day's “Enough” is a reflection, not a completion-percentage score. Reliability and a calm interface both serve that goal.
