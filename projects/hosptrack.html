HospTrack / Nursor

A hospital-workflow prototype connecting a spatial ward view, patient charts and natural-language navigation.

Prototype using synthetic records

Making context easier to navigate

A patient list, a chart and a floor plan each reveal a different part of a hospital workflow. This prototype brings those views together, with a 3D/2D spatial interface and AI-assisted chart briefings.

What I built

  • A React and Three.js interface for exploring wards and selecting synthetic patient records.
  • Gemini-generated chart briefings, with caching and batched preload to avoid repeating the same requests.
  • A natural-language command bar that translates requests into structured interface actions.

The engineering focus

The project connects model output to a bounded set of UI actions. It also makes spatial context useful without forcing the user to navigate the entire workflow in 3D.
